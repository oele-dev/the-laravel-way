# The Laravel Way

Conventions of the Laravel ecosystem that are easy to get wrong, because the sources disagree or because nobody wrote them down. One file per convention.

I keep this for my own projects and for the coding agents that work on them. Each page is short enough to read in a minute and plain enough to paste into an agent's rules.

## How a page decides

Laravel Boost and Spatie's guidelines are both good, and they contradict each other in places. When they do, the framework breaks the tie. In order:

1. What Laravel generates and documents: the `make:` commands and the official docs.
2. Laravel Boost's guidelines.
3. Spatie's guidelines.
4. What the community does.

Every claim links to the file it came from, pinned to a commit, so you can check it and see when it goes stale.

The framework's answer is the Laravel way. Each page then gives my verdict, which can depart from it. When it does, the page says why and what it costs.
